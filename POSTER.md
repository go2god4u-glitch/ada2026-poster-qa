# Poster QR Copy (ADA 2026)

Print this text next to the QR code on the poster. All visitor-facing language is English.

## Call-to-action (pick one)

- **Scan to ask the presenter — get a live reply.**
- **Questions? Scan the code and chat with us in real time.**
- **Scan to message the presenter directly — no app to install.**

## Privacy note (one line)

> Your name and company are shared with the presenter; email is optional and only used if we follow up.

## QR sizing & generation

- Size the QR code **at least 3 cm × 3 cm** (larger is better) so it scans reliably from a normal standing distance.
- Generate the QR with `gen_qr.py` and use its PNG output (saved to the Desktop). Do not screenshot or rescale the code — embed the original PNG to keep it crisp.
- Quick visual check: scan it yourself from ~1 m before printing.
